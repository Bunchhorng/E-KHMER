# Image generation prompts

Created with the built-in imagegen tool. The primary logo was generated with transparency; all other assets were generated using that logo as the reference image and an opaque background.

## logo-primary

```text
Use case: logo-brand.
Create a polished new primary logo concept for E-KHMER, an existing Cambodian online marketplace and seller/admin platform. This is a practical modern evolution of a blue-and-gold identity, for a bilingual Khmer/English product.
Asset: one standalone horizontal primary logo, generous transparent margin, transparent background, crisp flat vector-like execution. No board, no mockup, no paper, no checkerboard.
Design direction: "Market Gate". A simple confident geometric shopping-bag / market-gateway symbol, with a subtle three-step Khmer architectural rhythm at its top and a clear open negative space. Use very few shapes: deep navy body, cobalt blue architectural / handle detail, one restrained warm golden accent. Contemporary and legible when reduced; local cultural character without ornate religious ornament. No detailed temple illustration, no gradients, no 3D, no thin outlines.
Place the symbol to the left of the wordmark. Exact wordmark: "E-KHMER", uppercase, bold refined geometric sans, deep navy, comfortably spaced. No other text or slogan.
Palette: navy #0B1739, cobalt #2563EB, warm gold #F2B544. Strong clean silhouette. Wide landscape composition around 3:1, with the mark and wordmark aligned centrally, large and perfectly readable. Professional identity presentation ready for a team branding concept.
```

## app-icon

```text
Use case: logo-brand. Asset: standalone square app icon for E-KHMER. Reference image is the approved concept logo; it is an identity reference and edit source, not a mockup to reproduce. Extract and reuse ONLY the shopping-bag / stepped Khmer market gateway symbol from the reference. Preserve its distinctive handle, bag silhouette and gold gateway exactly; remove the entire wordmark. Recolor the bag silhouette white, retain a rich golden gateway #F2B544, white or light-blue handle. Put the symbol centrally on a uniform cobalt #2563EB square canvas. Artwork centered at about 65% of canvas width, generous safe area, fully opaque edge-to-edge square background, no baked outer rounding (OS applies the mask). Crisp and flat, no gradient, no texture, no shadows, no extra container, no device mockup, no text, no watermark. Output one high resolution square icon.
```
